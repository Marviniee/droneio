# DroneIO

Persönliches Merkblatt für den Drohnenbetrieb A1/A3 (DJI Mini 4 Pro & DJI Neo 2). Statische HTML-Seite, keine Backend-Abhängigkeiten, als PWA installierbar (Add to Home Screen).

Live: https://marviniee.github.io/droneio/

Quelle des Regelwissens: LBA-Online-Kurs "UAS A1/A3" + offizielle DJI-Herstellerangaben. Gepflegt im Obsidian-Vault unter `02 Projekte/Drohnenführerschein A1-A3/`.
