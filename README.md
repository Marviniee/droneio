# DroneIO

Persönliches Merkblatt für den Drohnenbetrieb in der EU-Kategorie A1 (C0-Klasse, unter 250 g). Statische HTML-Seite, keine Backend-Abhängigkeiten, als PWA installierbar (Add to Home Screen).

Live: https://marviniee.github.io/droneio/

Quelle des Regelwissens: LBA-Online-Kurs "UAS A1/A3" sowie öffentliche Hersteller-Spezifikationen.
